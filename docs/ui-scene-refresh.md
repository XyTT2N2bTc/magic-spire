## RuleChangePackage · 2026-09-14

在当前工作区实施 PR #1 的场景拆分方向，不合入旧 PR 的规则或物品分支。`ui/shell/game_layout.tscn` 保留背景及当前使用的立绘；`header.tscn` 与 `body_sidebar.tscn` 承载顶栏、身体栏静态布局；`ui/elements/` 中的 arena、enemy_group、equipment_portrait 场景管理角色展示。主界面继续负责正式候选提交和页面编排。

每次界面更新清理临时控件，不销毁仍使用的立绘。身体外观按实际显示字段比较，不缓存整个规则状态或候选；姿势、装备外观和固定立绘偏好改变时更新。固定立绘忽略不会改变图片的姿势／装备变化。敌人按稳定 ID 保留分组，仅外观字段或对应素材设置改变时更新，离场删除。程序绘制敌人不再有空闲逐帧重绘或浮动动画；纹理立绘同样不逐帧位移。背景飘尘保留原独立动画。

身体栏在同一界面连续刷新时复用，收起或离开不需要它的页面时释放；再次展开按当前 View 构建。显示时恢复原兄弟节点顺序，不能只依赖 z_index，否则 Godot 的鼠标命中可能先落到商店整页面板上。模态抽屉仍位于交互层最上方。

影响项：UI 节点所有权、生命周期、素材刷新和布局。状态、数值、候选、事务、固定点、回合、随机域、十四规则交互轴、存档及迁移均不变。changedUiAndLogs：保留现有中英文、规则原因、信息摘要和对白，日志 N/A（仅展示层拆分，没有新增事件）。不重写正文。

验证复用 display 的节点复用／空闲重绘计数／姿势变化／只读检查，以及 hero_art、equipment_art 的装备、姿势、固定立绘分支。其余受影响界面分类检查拖放、服务、奖励、地图和布局。使用既有检查入口，不新增截图，执行结果记录到 docs/verification.md；未执行前不标记 Verified。

大版本完成后自动同步 GitHub 的范围及失败边界同时写入项目与上级 AGENTS.md；不在本批次提前发布尚未完成的 v0.17。
