# PC键位

设置分为“显示”和“键位”两个页面。键位页支持修改按键、组合键、冲突提示、恢复默认，以及可选的长按0.5秒结束回合。Esc固定用于取消和返回；改键时按Esc只取消当前改键。键位保存至独立的`user://key-bindings.cfg`，不写入游戏存档；Android继续使用触屏操作。

| 默认按键 | 操作 |
| --- | --- |
| 1—9、0 | 选择从左到右第1—10张手牌，不立即使用 |
| R | 翻转选中牌／切换选中基础动作；无选择时操作鼠标悬停的卡牌、基础动作或蓄力图标 |
| Space、Enter | 使用选中牌／动作，对当前选定目标结算 |
| Tab、Shift+Tab | 循环选择当前牌／动作的合法目标 |
| E | 结束回合；默认点按，可开启长按 |
| Z、X、V、F | 选择肘击、近身短打、腿部动作、火球术，再确认或点击目标 |
| A、D、C、P | 抽牌堆、弃牌堆、完整卡组、能力区；同键关闭 |
| I、B、S、M、L | 道具、身体与拘束具、状态、地图、行动日志 |
| Esc | 优先取消选择，再关闭窗口，最后打开菜单 |

数字选牌会显示该牌当前效果，合法目标在原区域高亮。目标条可点击确认，箭头与Tab用于切换；敌人目标可直接鼠标点击。手牌和常用按钮显示实际绑定按键。输入框保留正常文字输入；弹窗中的键盘确认和焦点移动限制在当前窗口，不触发背景行动。键盘重复事件不连发；丢失焦点会取消结束回合长按。视图版本改变、重开和加载会清除待确认动作。

实现分工：`key_bindings.gd`只维护本地配置与键位页，`keyboard_input.gd`只维护UI选择，合法目标、高亮及恢复共用`DragTargets`与ActionIndex中的现有候选；支付和规则结果仍由`main._submit(candidate, expected_version)`完成，右键切换复用原CardFace／控件回调。鼠标选择部位后按确认使用最新选中的候选，不另选其他目标。没有新增键盘专属规则或存档字段。

检查入口：`tools/check.ps1 -UIOnly -UISuite keyboard`；显示、普通导航、主页和事件窗口分别复用display/interface/home/events分类，触屏复用touch分类。默认不截图，键位页代表性截图按`-Screenshots ui-key-bindings.png`显式生成。

商店付款演出显示时，键盘焦点限制在该演出内；Tab选择按钮，Enter或空格沿原控件确认。Esc和其他快捷键不会打开背后的页面，确认只关闭表现，不会重复付款。

付款弹窗范围由main.modal_region共用识别；Android系统返回键调用该弹窗原确认按钮，优先关闭演出，不打开背后菜单，也不重复付款。

统一奖励列表、选牌页和Boss遗物页共用当前弹窗键盘范围：Tab／Shift+Tab循环选项，Enter／空格操作选中的原按钮，R翻转鼠标悬停的奖励卡牌。Esc先返回奖励列表，不会自动领取或跳过。抽屉打开后，其键盘范围优先于背后的奖励页。
