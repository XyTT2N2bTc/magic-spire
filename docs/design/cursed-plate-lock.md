# 诅咒平板锁

本文件是 Boss 遗物「诅咒平板锁」及其专属分支的唯一真源。普通三型号平板锁（中级负数平板锁、中级负数平板锁（导尿管）、高级负数跳蛋锁（导尿管））、加固带、S 公式与滑精机制见 `./equipment-design.md` §11.1；本分支只写差异。

代码真源：`data/relics.gd::BOSS_POOL/TYPES.cursed_plate_lock`、`data/special_equipment.gd`（`cursed_plate_lock`、`CURSED_VIBRATOR_TURNS`、`CHASTITY_CLIMAX_FACTOR_LIMIT`、`CURSED_PLATE_REASON`）、`core/game.gd::cursed_plate`、`core/relic_effects.gd::boss_key`、`core/pressure.gd::_apply_overloads`；回归用例 `tests/cursed_plate_cases.gd`。

## 1. 发放与安装

- Boss遗物，沿既有Boss三选一与第0层“失去余烬护符换随机Boss遗物”发放，能量上限＋1。
- 拾取时强制安装独立的 `cursed_plate_lock` 分支：以高级负数跳蛋锁（导尿管）为基础，紧度3档、自动上锁并附加专属加固带，锁体持续时间无限。安装按原平板锁覆盖规则替换冲突装备。
- 不受“贞操锁池”随机开关与概率影响，也不进入敌人或监狱的随机池；普通性玩具不能把它作为替换目标。

## 2. 默认规则与抖M偏好

- 默认版内置跳蛋只在每场前6个玩家回合开始时产生刺激（`CURSED_VIBRATOR_TURNS`）。战斗与其整备属于同一场次；休息、牢房探索与新战斗沿既有场次入口重新获得6回合。导尿管随消耗能量行动触发的刺激不受该限制。
- 高潮后快感保留系数从3开始、每次高潮＋1，默认最高10；连续高潮按上限计算并保存封顶后的系数。
- 主页“抖M专用版”偏好只在新局建立时写入权威状态：开启后该局恢复旧版规则（跳蛋不受6回合限制，保留系数不设上限）。恢复存档不读取主页当前值。
- 偏好同时决定第0层开局：开启时初始遗物替换为诅咒平板锁，开局选项由四类变为三类（卡牌／资源／代价各一项），详见 `./game-design.md` §9.4。

## 3. 不可提前解除

只有这一分支及其所属加固带禁止提前解除：普通开锁、滑脱、伤害、整件解除、henshin、事件暂存、替换与续塔清理都不能移除它们。原版平板锁及其他装备不变；原版的品质、刺激、上限、倍率、导尿管与立绘判定继续复用，不建立第二套计算。解除入口只给出共用原因 `CURSED_PLATE_REASON`（“诅咒平板锁只能用下一个Boss掉落的专属钥匙解除。”）。

## 4. 专属钥匙

持有遗物后首次真正击败下一位Boss，在正常战斗胜利流程中获得并立即使用专属钥匙，自动解锁并取下锁体与附带加固带。

- 无需额外点击，不生成背包物品，不检查姿势、身体、能量、魔力或背包容量；收押、饱和结束、事件战斗与监狱出口战都不发钥匙。
- 获得遗物时已经击败的Boss不计入；完成后不再掉落，遗物与能量上限加成保留。
- 状态新增 `cursed_plate_released` 布尔值；取得条件为：非饱和结束、全部敌人已击败、房间标记为Boss、非监狱出口战、遗物在手且未领取过、且场上恰好存在一件诅咒平板锁。

## 5. 存档与展示

- 快照校验：未领取时必须保留唯一、三档、上锁、无限持续的锁体；已领取时不得残留该锁，且必须仍持有遗物。无旧档迁移。
- 遗物详情、图鉴、当前进度、装备详情、状态悬浮窗、教程与日志同步，使用独立锁图标。
- 装备正文只展示当前刺激方式、触发时机、最终数值与高潮保留公式；加固带明确不产生独立刺激。
- 规则案例归 `relics`（`tests/cursed_plate_cases.gd`），全注册表安装案例归 `special_equipment`，主页偏好归 `display/home`，图鉴窗口归 `encyclopedia`。
