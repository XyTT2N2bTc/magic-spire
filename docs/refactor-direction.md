## 1. 重构对象与边界

动：核心的按需构建范围、核心→UI 的投影复用、UI 的节级刷新、失败路径的重算边界，以及把它们锁住的度量。

不动：规则内核（判定表达式与数值）、状态结构与存档格式、随机域、事件与迁移管线、两个 oracle 的输入域与断言、玩家可见文案与行为。

理由：三条已成立的不变量是资产（核心唯一权威、唯一提交入口、确定性可回放）；oracle/digest 是唯一可信回归面，动输入域等于自毁验证；规则内核与本次症状无因果。

## 2. 目标形态（可验收）

- **T1** 一次提交的成本 ∝ 该操作写入的字段集合，不 ∝ 世界大小；每次有效操作 **0 次全局候选筛查**。
- **T2** 一次界面刷新 ∝ 该操作改变的显示节；整树重建只作兜底（读档／新局／快 SL／相位切换等具名入口）。
- **T3** 失败路径不重算：同版本被拒只刷 notice，版本落后被拒才重同步（`docs/response-pipeline.md` §7 已定）。
- **T4** 玩家可见行为、存档、两个 oracle 的 digest 逐字不变。
- **T5** 每次点击的段成本可测且入门禁（P0 协议），回退可判红。

## 3. 原则

### 3.1 不变量改写（待 D3）

把"禁止跨提交缓存规则结果"改为：**复用必须附可证失效规则；无证明即禁止**。
证明形式由规划者定义，可取"字段依赖表 ＋ 写入差分"，或等价的机械断言；**证明必须能在门禁里红**，否则不算证明。

### 3.2 分层归属（现行事实写清，避免再次误读）

| 层 | 可持有什么 | 失效由谁给 |
| --- | --- | --- |
| 核心 `core/` 单次只读调用内 | 索引、预览、合批等调用内复用（现状保留） | 调用作用域结束即失效（state 身份／显式 scope） |
| 核心→UI 的投影 | UI 的 `view`／`actions` 跨操作持有 | **核心给出**的作废集合（写差分 × 字段依赖表） |
| UI 本地显示态 | 节键、翻面、抽屉开合、`_button_index` 等 | 节键比对（`docs/response-pipeline.md` §4.2） |

### 3.3 保留不变

核心唯一权威；UI 不判规则、不复算资格、不按译文／颜色／名称识别对象；确定性输入域不变；提交入口唯一。

## 4. 分期（每期独立验收，不许跨期吞并）

- **P1 候选增量**：`docs/candidate-delta.md` 契约（目标 0 次全局筛查／操作）＋ §6 注（A6）与代码同批落地。
- **P2 界面增量**：`present(dirty)` 落地（§3.2–§3.4 草案转正；`body_sidebar._presentation_key` 作为既有样例复用）。
- **P3 失败面收窄**：§7 同版本被拒零重算 ＋ `get_view` 白名单复核 ＋ 9 处外部 `render(view)` 兜底调用点收窄（需扩展授权，§5-1）。
- **P4 收口**：段成本度量入门禁；§4.1 正文改写；清理残留整树兜底。

依赖方向：P1 与 P2 可并行（一个改 core 侧、一个改 ui 侧，共同接口是"作废集合"）；P3 依赖 P1／P2 的作废集合可用；P4 最后收口。

## 5. 红线

- 不把规则或资格复制进 UI 换性能；不用"跳过投影／延迟刷新"替代失效证明。
- 不为提速放宽或删除断言；红集只允许已登记六项并逐条说明来源。
- 不改存档格式、随机域、事件管线；不新建第二套候选构建器或第二套规则内核。
- 任何"全局构建"必须留在合法入口并具名断言锁住（v2 §5.1）。
- 生产源码不留计时／计数钩子（P0 口径：仪器与 JSON 只进已忽略的 `build/`）。

## 6. 验收证据（每期）

配对测量（同机、同夹具、0／12／26／29 件 × 提交／选择／被拒三类）＋ 两个 oracle 逐字 digest ＋ 受影响套件 `unrun=[]` 且红集 ⊆ 已登记六项；**收尾**才跑里程碑全量（`-Suite all -UI -UISuite all`）。打包、发版、推送仍须用户明确指令。
