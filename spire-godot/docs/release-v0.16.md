# 紧缚尖塔 v0.16

免费发布，支持 Windows 64 位和 Android ARM64／ARMv7。

## 2026-09-13 六缚计数热修复

六缚只计算本场战斗的次数：第四次开始准备逮捕，此后规则不变。事件、休息、牢房和此前战斗的次数不再提前触发她的逮捕。图鉴及英文说明同步。

同时隔离未开放角色的提前卡牌注册，避免原角色读取卡牌说明时报错；不加入v0.17开发中的角色功能。

本次针对性规则检查2208项、文案与本地化检查446项通过，不代表全量回归。旧存档已经进入六缚战斗时仍保存旧门槛，请重新开始游戏。两端使用同一修复源码重打；版本号仍为0.16，Android安装版本仍为8。GitHub保持普通包，双层加密包只单独保存在本地。

## 本版更新

- 新增卡牌与关键词，调整卡牌、遗物、施法失败返还和商店价格。

完整记录随安装包提供，见仓库根目录的《版本更新内容.txt》。

## 下载与使用

- Windows：下载 `spire-v0.16-Windows64.zip`，完整解压后运行“紧缚尖塔.exe”。不要单独移动 EXE，PCK 和 content 目录必须保留在旁边。
- Android：直接下载 `spire-v0.16.apk`，或下载包含安装说明与更新记录的 `spire-v0.16-Android.zip`。安装版本为 8，包名和签名沿用上一版本。
- 旧版本存档不适配，请开始新游戏。安装包不包含开发者存档、个人设置或签名私钥。
- 普通游玩无需联网；主动提交游戏内反馈时需要网络。
- Android 包的签名、对齐与资源检查不等于真机验收；本版尚未完成安卓真机安装、显示和性能测试。
- 按发布要求停止本轮剩余回归，当前版本并非全量测试通过版本；仍保留未解决的测试失败记录。

文件完整性以随发布附带的 `SHA256SUMS.txt` 为准。当前 GitHub 发布的程序代码与下载包采用 GPL-2.0-only 许可，完整对应源码可从本版本发布页的 Source code 下载。图片、音乐、字体及其他非代码内容另按 `ASSET_RIGHTS.md` 及第三方许可说明处理；第三方组件保留原许可。
