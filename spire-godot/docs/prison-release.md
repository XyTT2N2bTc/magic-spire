# 监狱期限与出狱起点（2026-09-14）

## 巡视事件页（2026-09-14）

巡视沿用正式`inspection`规则阶段，但玩家界面固定使用独立事件页：紫发狱警立绘、阶段结果、叙事、对白与正式选项全部收在页内，不再额外弹出悬浮对白。狱警对白只说人物实际会说的话；延长刑期等精确数值留在结果栏，不由角色直接念出。

## 收押与巡视正文收口（2026-09-14）

战败后的`captured`阶段改为一次性的收押事件页。棕发狱警先将角色迅速押到登记台，随后按实际安装结果逐件显示普通或复合拘束具、连接绳和性玩具的共用佩戴正文；名称取自已提交的装备实例，不使用“新增几件”代替具体演出。页面仍保留警戒度、没收数量与本次榨取魔力，唯一正式入口为“进入牢房”。

收押处理完成时额外执行一次剧情榨精，复用脚本高潮结算，立即损失`min(20，当前魔力)`。平板锁与低魔力分别选择独立正文；平板锁分支改为揉捏乳房与小穴，使无法勃起的肉棒在锁下顶动并从缝隙流出精液。该次高潮不打开战斗高潮覆盖层，不增加高潮后乏力或滑精延迟。战斗结束与入狱遗物钩子保持原顺序，页面公开本次真实榨取值。

点击“进入牢房”后，收押页面及其两句狱警对白同时结束。收押对白不写入通用`npc_copy`日志，普通牢房回合不再反复取得同一条旧对白；例行巡视、额外巡视和正常出狱仍沿各自一次性NPC对白。

巡视页删除检查次数、清单登记原理、处罚事务边界、恢复牌区步骤和重复的反抗说明。结果公开时只写实际缺少的拘束具／性玩具及狱警准备补上的数量；没有缺失时写“一件也没少”。接受结果后只显示实际补回、没收、充电与刑期增加的短行。完整清单、替换对象、牌区恢复和电量结果继续保存在原结构化检查事件中，不因缩短显示而删除。

RuleChangePackage：影响正式收押的自身魔力、高潮总数、特殊装备高潮反应、捕获记录中的可选结构化`intake_scene`、收押页面和中英文正文。装备先由既有Application事务完成，随后执行一次脚本高潮，再以提交后真实装备生成页面；普通单件、复合根、连接绳和性玩具分别复用权威佩戴正文。候选仍只有既有`prison.enter`，页面不增加绕过事务的入口。检查、补装、没收、充电、刑期、巡视周期、警戒度、装备随机与位置资格、牌区、战斗奖励及后续牢房回合保持不变；不增加随机域或快照修订，旧存档缺少可选演出字段时使用简短安全回退。十四轴中资源、高潮、特殊装备反应、阶段显示与文案受影响，其余装备层级、锁、部位、姿势、移动、伤害和施法N/A。验证覆盖正常20点扣魔、低魔力归零、平板锁差分、具体装备正文、存读档、旧对白不复现与收押事件页；不截图、不打包、不发布。

## 巡视榨精与狱警对白（2026-09-14）

每次玩家接受例行巡视的检查结果后，紫发狱警额外用手榨精一次；刑期到期触发的额外巡视也执行同一项榨精，由棕发资深狱警负责。一次巡视只结算一次高潮，重复提交已完成阶段不能重复触发。高潮沿现有身体、装备和遗物规则结算，精液中储存的自身魔力立即损失`min(20，当前魔力)`；魔力不足20时降至0，并使用低储量文案。事件式强制高潮不打开战斗高潮覆盖层，不增加高潮后乏力，也不启用滑精的两回合延迟扣魔力；即使平板锁与导尿条件令机械日志判为滑精，本次仍一次性扣除对应魔力。

平板锁佩戴中改用独立演出：狱警先对锁下无法勃起的肉棒表示惊讶，随后坦然揉捏乳房与小穴，使精液从锁具缝隙流出；是否低储量继续使用结算前魔力判定。正常手部榨精与平板锁差分均由稳定文案cue选择，不从显示名称或正文推断装备。对白栏只显示狱警说出口的话，不带人物名字；第二人称动作演出进入叙事栏。例行巡视显示紫发狱警，收押、到期额外巡视与正常出狱对白显示棕发资深狱警。正常出狱完成后，即使场景已切换到新塔路起点选择，仍弹出一次无名字的狱警对白框。
