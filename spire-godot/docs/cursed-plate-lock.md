# 诅咒平板锁（2026-09-13）

Boss遗物，沿既有Boss三选一与开局Boss遗物交换发放，能量上限＋1。拾取时强制安装独立的`cursed_plate_lock`分支：以高级负数跳蛋锁（导尿管）为基础，紧度3档、自动上锁并附加加固带，持续时间无限。安装会按原平板锁覆盖规则替换冲突装备；不受普通随机锁池开关影响，也不进入敌人或监狱随机池。

只有这一分支及其所属加固带禁止提前解除。普通开锁、滑脱、伤害、整件解除、henshin、事件暂存、替换和续塔清理不能移除它们；原版平板锁及其他装备不变。原版的品质、刺激、上限、倍率、导尿管和立绘判定继续复用，不建立第二套计算。

持有遗物后首次真正击败下一位Boss，在正常战斗胜利流程中获得并立即使用专属钥匙，自动解锁并取下锁体与附带加固带。无需额外点击，不生成背包物品，不检查姿势、身体、能量、魔力或背包容量。普通战斗、战斗饱和结束、事件战斗与监狱出口战不发钥匙。获得遗物时已经击败的Boss不计入；完成后不再掉落，遗物及能量上限加成保留。

共用候选提供专属钥匙的具体原因；提交仍复核并原子回滚。新增`cursed_plate_released`布尔状态，当前快照修订44，校验待解除时必须保留唯一、三档、上锁、无限持续的锁体；完成后不得残留该锁。无旧档迁移。
