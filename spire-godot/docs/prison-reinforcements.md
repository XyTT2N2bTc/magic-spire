# 监狱探索警卫战：援军

## RuleChangePackage · 2026-09-14

以用户最终要求为准：援军是开战即生效的场地负面效果，不新增警卫意图，不等待施加捕缚，不按警卫各自计时。仅监狱探索反抗巡视警卫战生效，监狱出口战及普通警卫练习不生效。

第4、8、12……个完整战斗回合结束时召来1名中级警卫，整场共享上限1＋当前警戒度。先后手共用回合结束边界，不因打断或原警卫阵亡重置。新警卫走正式敌人创建、生命缩放、独立立绘随机与原意图，下一回合开始行动。胜利立即结束效果，奖励和整备不计数；失败再入狱清理旧战场，新反抗战重新计数。

在prison内保存本场已召唤数量，倒计时由正式战斗回合派生。候选／事务沿用结束回合、攻击、入狱、反抗；查看不推进或消耗随机。快照检查数量类型、来源及上限，缺少数量的旧反抗战存档拒绝恢复，不创建迁移。changedUiAndLogs：状态面板与常驻图标显示援军、剩余回合、已召唤／上限；开战和真实抵达日志及英文同步。原敌人意图和叙事不变。十四交互轴仅战斗回合、敌人数量、环境状态、快照及既有召唤生命缩放受影响；装备、锁、层级、资源、姿态、工具、移动、费用、奖励规则不改。

测试归prison，关联enemies／guard／status／persistence／content：3／4回合边界、先后手、总上限、出生回合不行动、原警卫阵亡、胜利取消、出逃排除、只读及坏存档原子拒绝。窗口复用guard，不截图、不打包。结果见verification.md。
