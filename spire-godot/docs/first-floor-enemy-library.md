## 漂浮玩具箱

准备 → 佩戴 → 停顿，三步循环；不会自行离场。

- 准备：按当前容量与同类限制，从敌人通用初级池中等概率选一件可安装装备，并公开名称。当前为八件：nipple_clamp_low、nipple_ring_low、shaft_ring_low、corona_ring_low、urethral_rod_low、vaginal_egg_low、anal_egg_low、crotch_rope_low。全部飞机杯不进入敌人通用池，外置震动棒只从中级池开始出现；监狱独立池不改变本怪名单，以后新增定义也不会自动入池。
- 佩戴：只安装已准备的这一件；共用正式特殊装备资格与安装工厂，保留原持续效果、耐久和容量规则。期间位置被占用或出现同类装备时失败，不暗中换抽，不替换已有装备。
- 停顿：不佩戴、不加固、不补电；之后重新准备。已有装备的正常回合效果仍照常发生。
- 没有合法候选时仍按三个步骤推进，出现空位后在下一次准备时重新检查。
- 击败箱子取消尚未执行的安装；已佩戴装备保留。所有敌人离场后共用原奖励流程，只发一份奖励。

## 打断、存档与随机

打断仅推迟当前步骤，不消耗步骤、不重抽已经准备的装备。提前击败取消未来行动。预览／图鉴不消耗随机；准备结果随敌人真实实例保存，读档原样续接。后手时完成停顿后可以暂时没有下一步计划，直到下一回合正式准备，不由页面提前计算。

## 漂浮锁

预告上锁 → 上锁，两步循环。只给已有合法装备上锁，不施加皮带、不加固、不改变原等级、耐久或紧度。打断延后当前步骤，执行时从仍合法的装备中选取目标。入场没有可上锁目标时仍不抽取漂浮锁。

## 意图生成与出手时机（2026-09-08，加固时机已接入）

本轮完成加固意图的两个时点处理，并通过意图规则与窗口专项。生成时改选、出手时空过适用于单次及批量加固；不会因本节验证通过而把其余施加／替换和下方敌人设计标为全部完成。

- 加固意图不指定具体目标。所有没有明确声明指定目标的施加类行动，只在怪物实际出手时按玩家当时状态寻找目标；预告可以确定行动种类、数量、品质、紧度及装备池，不提前抽取具体装备／部位目标。预告中的“随机装备”也在出手时从已声明池选择，除非该行动本身明确规定提前准备某件具体装备。
- 生成加固意图时只检查是否有合法加固目标，不冻结目标。如果没有，则从该怪物本来拥有的施加拘束具意图中随机选一个作为此次预告，保留所选意图自身的数量、池、等级和紧度；之后继续原行动序列，不重置循环。没有这种意图则空过，不补造能力。
- 已生成加固预告，轮到实际执行时再次检查：仍有任一合法目标就按当前规则选取并加固；全部无目标则本次空过，消耗该次行动、推进行动步骤，不改成临时施加。
- 因而玩家只解除一件，并不能保证加固落空；需要让出手时全部合法加固目标消失。加固者不能加固最高档装备或不支持通用加固的特殊装备，不能只按装备件数判断资格；平板锁达到3档自动附加加固带不属于敌人的普通加固候选。
- 批量加固在执行时缺额的部分同样空过，不用临时施加补齐；明确包含独立施加步骤的复合行动，仍按其已声明步骤执行。
- 明确指定目标或明确规定提前准备具体装备的行动保留其专门声明，不因这条通用规则抹去特例。后续迁移应逐条核对这些声明，而非把所有既有预备字段一律保留为例外。
- 特殊装备具有“拘束具”词条，但可加固、可锁、可替换资格继续读取自身规则。
- 不采用此前建议的“按后台强度分三级改选”，也不新增“弱怪／强怪不同改选能力表”；最终方案以正常施加逻辑和上述两个时点的加固处理为准。

施加与替换的完整定义只维护在[装备设计](equipment-design.md#application-replacement-design)。事件可共用施加入口，但事件的冻结选择、费用、结果及替换权限仍由事件声明，不把事件强行套入怪物回合。

## 人形强怪：被魔法控制的奴隶贩子（已接入独立练习）

- 分类：人形／强怪；生命56，后台强度为2。强度只用于以后可能配置的怪池组合，不决定品质、生命或改选能力。
- 已注册敌人、图鉴和单体固定练习；与多面手组合加入第一幕强怪池，不加入弱怪池、精英房或塔顶。
- 使用人形替换权限、普通施加逻辑及上述意图时机。通常随机施加使用普通池；未明确调用复合池的步骤不得抽取复合装备。

### 行动表

下列1／2／3／4为动作标号，不是永久绑定的全局回合号。首次依次执行1→2→3→4，之后循环1→3→4；累计三轮后执行逮捕。

| 动作标号 | 内容 | 调用规则 |
| --- | --- | --- |
| 1 | 随机施加2件随机种类的初级拘束具，紧度2，不包括口球 | 普通池施加；满位且符合权限时进入替换；装备与部位出手时选定 |
| 2 | 给玩家1层无力化，持续1个玩家回合 | 状态施加，不进行装备施加／替换 |
| 3 | 施加1件随机中级拘束具，基础紧度2；随后自身获得1层准备就绪 | 普通池施加＋独立状态增加；已有准备就绪可作用于本次装备 |
| 4 | 优先在中级马具口球与中级眼罩中寻找可施加方案；正常情况下受到动作3的准备就绪影响，紧度为3 | 明确的普通装备范围；对应位置满位时检查替换，两处均无解时改选本次允许的其他普通拘束具／部位，保持中级及实际紧度，不扩大到复合池 |
| 逮捕 | 完成规定循环后执行逮捕，接入既有收押／入狱结果 | 逮捕流程；不把逮捕伪装成一件装备施加 |

动作4的马具口球是已存在的 `mouth_band` 中级版本0，单件、口部容量1、一条耐久；不新增同名复合装备。当前普通白名单只包含已登记的绳索、细绳、皮带、细皮带、胶带、扎带、胶带眼罩和堵嘴胶带；中级另外允许皮革眼罩与口球。包含绳索或皮带类的普通池自动拥有合法链接绳候选。布带眼罩、复合装备、特殊装备和以后新增的普通模板不会仅因注册自动加入。

### 无力化

禁止基础攻击，魔法不受该状态限制；挣扎、滑脱、移动、道具仍按各自原资格执行。持续覆盖玩家接下来一次行动回合，结束后移除，不设为整场持续效果。实际禁用原因及状态剩余时间应来自该效果本身；强制结束该玩家行动回合也应正常消耗这一回合持续期。

### 准备就绪

允许叠层，不使用此前建议的最多1层。每成功施加或替换一件装备消耗1层，将该件紧度固定为3档；不是给紧度再加3，也不是一次消耗全部层数。没有合法目标、施加失败或行动被打断时不消耗。批量施加逐件消耗，有几层就依次作用于几件；一次完整复合安装按一件计算，不按组件扣层。

每件装备先读取已有层数确定实际紧度，再进行选装、替换比较和安装。动作3若开始时已有准备就绪，先让本次成功安装消耗1层，再按动作描述获得1层；若本次没有安装成功，则保留旧层并仍获得本步声明的新层。不能提前使用本步结束后才获得的层数。准备就绪不能降低装备结构本身的最低安装条件。

### 已冻结边界

1. 首次1→2→3→4计为第一轮，完整序列是1→2→3→4→1→3→4→1→3→4→逮捕；第11次实际行动调用现有收押流程。
2. 打断只延后当前行动，阶段、准备就绪层数和累计次数都不前进；下次敌方阶段执行原行动。
3. 当前普通白名单为显式配置；三档装备可能带来的既有附属效果继续读取装备模板，不另设奴隶贩子专用版本。
4. 当前通过明确登记的“多面手＋奴隶贩子”组合进入随机强怪池；图鉴和固定练习本身不会自动生成配队。

## 人形强怪：多面手（已接入独立练习）

- 分类为人形／强怪，生命60，后台强度2。已注册图鉴、代码绘制外观和独立练习；与奴隶贩子组合加入第一幕强怪池。
- 独立练习在手腕和小臂预置两件初级1档皮带，供上锁与加固分支演示。正式敌人不自带这些装备，始终读取战斗现场。
- 性玩具安装具有正式人形替换权限；特殊装备仍按自身容量、同族、品质、紧度和替换比较规则处理。平板锁安装时自动上锁、3档自动附加专属加固带，并使用自己的单向升级规则，不获得普通性玩具的替换权限。

| 行动 | 效果 |
| --- | --- |
| 第1回合：发呆 | 不安装、不加固、不改变状态 |
| 第2回合：安装性玩具 | 随机安装一件初级2档性玩具 |
| 第3回合：控制装备 | 在可成立的行动中等概率选择：随机上锁一件可上锁拘束具，或随机加固至多两件拘束具到3档 |
| 后续 | 第2、3回合持续循环 |

动作3形成意图时检查两种分支：两者都成立则各50%，只有一种成立则直接选择；两者都不成立时，沿通用加固改选规则变为本怪的性玩具安装意图。分支预告后冻结，具体上锁或加固目标在出手瞬间随机选择；预告后目标不足的部分落空。打断只延后当前预告，不重抽分支。

初级随机池由`SpecialEquipment.RANDOM_POOLS[1]`统一维护，不含任何飞机杯，也不含`external_wand_low`。中级池保留`external_wand_medium`，同样不含飞机杯；开启主页“贞操锁池”后，中级池另含两种中级平板锁，高级来源可使用高级跳蛋锁。锁分支默认25%，可按5%调整；当没有合法锁或升级时不掷空，概率完整归还普通性玩具。这里描述的是敌人通用池；监狱独立池从警戒度3级起允许飞机杯，不会反向改变多面手或玩具箱的名单。

## 2026-09-09 魔导拘束盒

- 机械类强怪，64生命，后台强度4。注册单只强怪组合 `binding_box_solo`，加入强怪池、图鉴和独立练习；沿用不连续抽到相同组合的规则，不生成多只拘束盒。当前八种强怪组合见上方组合表，均总强度4。
- 坚硬沿用机械类非魔法伤害×0.5。普通主动池为皮带、细皮带、皮革眼罩和口球，并沿通用皮带池规则包含合法链接绳；回合被动池仅皮革类。没有额外免费补端。
- 第一回合直接施加40/100捕缚。固定坐姿，上身受限至少1级；每个玩家回合开始、抽牌之前施加1件中级2档皮革拘束具，再增加10捕缚，无合法佩戴位置仍增加10。同种不叠加；已有不同捕缚时只加本来源初始值一半，即20。归零后准备一回合再施加，来源离场后效果停止。100后下一敌方阶段收押，复用已预告行动快照。
- 捕缚生效后的循环：①等概率施加2件中级2档自有池装备或累计加固皮革4档；无可加固目标只选施加，预告后失去目标则空过。每档沿原加固规则执行，最高3档，不加固口球或绳材链接。②准备一回合。③在剩余且可佩戴的备用复合装备中随机选一件施加；全用完后此步骤改为捕缚＋10。
- 备用库存三件各一件，均中级2档：上段单腿套（大腿根—膝上）、下段单腿套（膝下—脚踝）、短型直肩带单手套（手部外露）。成功才消耗，失败保留；解除并重新捕缚不补货。库存索引随敌人实例保存，不另造物品栏或安装接口。
- 机械类的复合施加获得正式替换权限，普通装备不扩权；满位比较、外层限制、链接维护和组件原子处理全部复用Application／Replacement。库存选择在出手瞬间进行，预览与恢复不重抽。
- 状态栏显示库存及坐姿捕缚效果，敌人立绘沿原代码绘制入口；快照版本只读取Snapshot.REVISION，不迁移旧档。
