## 必须遵守的架构

- core/game.gd 是状态与事务唯一提交入口。
  core/game_view.gd 生成只读显示快照；UI 不读取或修改 game.state。
- UI 提交已有候选 ID＋版本；action_index 只查找，不重算资格。
- ui/target_queries.gd 共用身体目标归并、拖放载荷与解除候选查询，
  只接受View数据和ActionIndex，不持有游戏、控件或跨刷新缓存。
  自动唯一目标、手牌目标去重及首／末不可用原因各保留原有语义。
- core/pressure.gd 等助手沿正式初始化、行动、回合管线执行，
  不提供另一套玩家命令；失败必须完整回滚。
- balance、card_rules、relics、enemies 等注册表集中维护数值。
- data/field_tools.gd 只维护工具注册表与不读取状态的说明；
  core/tool_rules.gd 继承同一注册表并承接触及、安装、取回和实时说明。
  规则内继续使用 g.Tools，不在数据层恢复状态查询或复制第二份数值表。
- 敌人种类与实例 ID 分离；意图、生命、来源和打断按实例保存。
- 查询、预览和公开意图不推进随机；随机结果按所属阶段冻结。
- 查询索引与完整参数相等的预览只在一次只读调用内复用；临时状态隔离，
  预览输入和返回容器隔离复制，正式执行重新计算，不跨提交保留。
- 装备安装、替换与删除复用工厂和统一清理；批次保留 protected_ids。
  普通件、复合组件、独立外带、链接与特殊根通过共用目标接口查询。
- 层级、真实覆盖、容量、锁、触及和操作来源必须同时复核。
  不用件数或区域标签猜左右手能力；不为特殊装备伪造普通容量。
- 正式练习先通过工厂初始化，此后的动作与玩家流程完全一致。
  不向 UI 开放夹具写入。
- 新功能先查现有模板、通用字段和事务；确有无法复用的边界时，
  向用户说明具体缺口并确认后再新增机制。
- 一次完成一个可试玩闭环；小修改不创建新流程文件。
  任务记录在 README，验证在 docs/verification.md，不另建重复看板。

## 界面、文案与素材

- 静态布局逐步由 .tscn 管理，脚本读取 View 并提交原候选。
  普通刷新保留立绘；只有真实外观、姿态、尺寸或设置变化才更新。
- 禁止每帧重画整套静态场景或销毁重建全部 UI。
  详情开合、翻面、选敌、滚动沿局部刷新保留焦点和位置。
- 抽屉、二级说明、模态焦点与关闭行为复用共享入口。
  遮罩关闭不能把点击穿透成背后行动。
- 拖牌以实际身体部位展开对应目标，提交前不付费；
  错误牌面不能自动改效果，锁定或无效目标保留具体原因。
- 状态、卡面、日志、对白与旁白各用对应投影。
  不重复规则说明，不删玩家决策所需的费用、概率和限制。
- 事件施加文案区分人物与附魔物自行动作，按 wear_style 选择。
  对白仅写实际发声，旁白为第二人称，不由文学正文补造规则。
- 语言由 ui/localization.gd 在显示边界处理。
  新文案优先稳定语义 ID，中文、英文与 source 校验同步。
- 兼容翻译仅匹配完整源句或受约束模板；缓存有界并随目录失效。
  译文、语言切换及显示设置不改候选、玩法存档或随机。
- 全语言使用内置字体及其许可，见 assets/fonts/SOURCE.md。
- 装备立绘统一由 ui/equipment_portrait.gd 组合，
  腿部读取真实 body_coverage.points，眼／嘴独立读占位。
- 战场拘束站姿复用装备立绘；坐、躺、自由、固定图各沿原入口。
  图片保持比例与真实透明通道，来源和处理坐标登记到美术说明。
- 马眼棒差分只在“任意平板锁＋内置导尿管或独立马眼棒”时显示。
  单独马眼棒不显示此锁体差分；只读映射不得改变装备效果。
- 外部素材只从授权来源导入，保留原图及处理记录。
  不擅自用生成式重绘替换用户确认的本地抠图。
- 显示偏好独立保存；不通过改角色状态实现固定图或语言选项。
- 快速 SL 与磁盘继续沿正式场景起点；
  精确快照、显示偏好、地图备注保持各自保存语义。
  快照版本以 core/snapshot.gd 为准，不擅自新增旧档迁移。

## 验证与发布

- 使用 tools/check.ps1 的退出码、错误日志、完成标记和源码指纹。
  source_changed 只报告断言结果，不能宣称冻结工作区通过。
- 测试复用现有分类和真实输入助手，覆盖费用、顺序、版本及交互。
  文案和注释不新增镜像测试，不删有效失败断言换取通过。
- 测试存档必须使用隔离目录，不能读取或覆盖玩家存档。
  正常数值试玩与缩短生命的夹具须明确区分。
- 不默认生成截图；必要截图是补充证据，不替代行为检查。
- .godot、build、依赖、用户数据及签名秘密不提交。
- 大版本里程碑完成且相关门禁通过后，自动核对并提交推送源码。
  不混入在途改动、不强推；遇权限或歧义冲突先报告。
- 自动源码同步不包含安装包、标签或 Release。
  小修改不代表大版本完成；打包发布沿用户明确要求。

## 代码规范

以下为本模块现状约定，检查工具覆盖不到，改动时人工遵守：

- GDScript 缩进是**每层一个空格**（不是四空格）；不重排函数、不批量格式化未触及的代码。
- 命名：变量与函数 snake_case，常量与 preload 类 PascalCase；判定只用稳定 ID（template/type/id）。
- 失败用返回原因字符串表达（空串=成功）或 `{ok,error}` 字典，不用异常；早退守卫写在前面。
- 注释写不变量、原因与边界（英文）；玩家可见文案与 docs 用中文。
- 新增文件须有明确职责边界与依据；大文件按职责拆，不按行数硬拆。
- 测试断言消息用英文并写明域；优先复用 `tests/` 既有夹具与真实输入助手。
