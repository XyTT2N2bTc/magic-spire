## 风险假设

`layout.begin_frame` 仍释放 `GameHeader` 与 layout 上的选择条／详情（`hero`／`body`／`enemies` 保留）。本次卸载留在 dirty 时，`present` 既有谓词会全量——⑧⑨ **允许**换 `GameHeader`，①–⑦ 的⑤仍须局部。过滤若改成「凡未挂载都留在 dirty」，`body_details` 普通攻击也会全量，⑤变红。`_picker_presentation_key` 不含手牌，未手选时普通攻击通常不让 `pickers` 候选；缺口在手选→清选中。夹具：`open_hand_selection` 只切 UI 态再 `render`；`selected_slot="wrist"`＋`show_body=true` 与 `present_routes_body_details_or_full` 同路挂载详情。游戏 `dispatch` 不读 `player_pick`，手选条挂着仍可 emit 合法攻击。若实现要新 UI 文件或 `commit` 新符号或 `kind` 脏表或类型化 `present` Array 或改谓词，停工交回，不新开模块迁就。
